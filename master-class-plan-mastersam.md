## 2. Что такое алгоритм

> **Слайды 3–4:** «Алгоритм — это рецепт» и «Результат».

**Ключевая мысль:** алгоритм — это последовательность действий, которая приводит к результату.

```text
Взять тесто -> добавить соус -> положить начинку -> поставить в печь -> получить пиццу
```

Что проговорить:

- У нас есть цель: приготовить пиццу.
- Действия нужно выполнять по порядку.
- Каждый шаг должен быть понятным.
- Если пропустить шаг или переставить шаги местами, результат получится неправильным.

Вопросы детям:

- Что будет, если сначала поставить тесто в печь, а потом добавить соус?
- Что будет, если забыть начинку?
- Какой шаг здесь первый? Какой результат мы хотим?

Попросить привести ещё 1–2 алгоритма из жизни: почистить зубы, собрать рюкзак, сделать бутерброд.

> Алгоритмы есть не только в компьютерах. Мы каждый день выполняем алгоритмы, просто не называем их этим словом.

## 3. Что такое блок-схема

> **Слайды 5–6:** «Фигуры блок-схемы» и «Блок-схема целиком».

**Ключевая мысль:** блок-схема — это алгоритм, нарисованный фигурами и стрелками.

- **Овал** — начало и конец.
- **Прямоугольник** — действие: «взять хлеб», «надеть куртку».
- **Ромб** — вопрос: «идёт дождь?», «сейчас зима?».
- **Стрелки** — порядок шагов.

Нарисовать вместе с детьми у доски:

```text
(Начало) -> [Взять хлеб] -> [Намазать масло] -> [Положить сыр] -> [Закрыть вторым ломтиком] -> (Конец)
```

> **Для преподавателя:** позовите активного ребёнка к доске, пусть остальные диктуют шаги. Мягко поправляйте слишком общие или перепутанные команды.

Переход:

> Пока все шаги идут подряд. Но иногда нужно выбрать действие в зависимости от ситуации.

## 4. Условия: «если…, то…» и `if/elif/else`

> **Слайд 7:** ромб «Идёт дождь?» с ветками «Да» и «Нет».

> Иногда в алгоритме нужно задать вопрос и выбрать, что делать дальше. Такой вопрос называется условием.

- Ромб в блок-схеме — это вопрос.
- Из ромба выходят разные стрелки, например «да» и «нет».
- От ответа зависит, какое действие выполнится.

> **Слайды 8–9:** «Условия в Python» и пример кода с погодой.

```python
if weather == "дождливо":
    print("Возьми зонт")
elif weather == "солнечно":
    print("Возьми солнцезащитные очки")
else:
    print("Не забудь проверить погоду")
```

- `if` — «если»: первая проверка.
- `elif` — «иначе если»: ещё одна проверка.
- `else` — «иначе»: запасной вариант.
- Команды внутри условия пишутся с отступом.

> **Для преподавателя:** не углубляйтесь в синтаксис. Главное — показать связь «вопрос в ромбе → условие в коде».

## 5. Практика: блок-схема Вити из карточек

> **Слайды 10–11:** «Знакомьтесь, Витя» и «Блок-схема Вити».

Сюжет:

> Витя хочет выйти на улицу. Но сначала ему нужно понять, какое сейчас время года. От этого зависит, что он наденет.

### Что должно получиться (режим «Только сезоны»)

| Время года | Что надевает Витя | Команда |
| --- | --- | --- |
| Зима | Тёплая куртка | `wear_winter_suit()` |
| Весна | Дождевик | `wear_raincoat_suit()` |
| Лето | Летняя одежда (футболка и шорты) | `wear_summer_suit()` |
| Осень | Школьная форма | `wear_school_suit()` |

### Как вести практику

1. Выложить «Начало» и спросить: «Что Витя должен узнать первым делом?»
2. Дети выбирают карточку-вопрос «Какое время года?».
3. По очереди разобрать четыре ветки. Для каждой дети выбирают карточку-действие.
4. Все ветки сходятся в «Конец».

```text
                 (Начало)
                    |
           <Какое время года?>
   зима /     весна |      лето |     \ осень
[Тёплая куртка] [Дождевик] [Летняя одежда] [Школьная форма]
        \           |           |           /
                  (Конец)
```

Наводящие вопросы:

- Если сейчас лето, должна ли сработать зимняя ветка?
- Сколько раз Витя должен задать вопрос про время года?
- Что будет, если забыть ветку для осени?

Если детей много, разделите их на четыре команды, по одной на сезон, а потом соберите общую схему.

## 6. Код на платформе: режим «Только сезоны»

> **Слайды 12–13:** «Команды для Вити» и «Давайте поиграем!».

Открыть платформу: `/?school=mastersam&mode=seasons`. Вверху справа должна быть выбрана кнопка **«Только сезоны»**. Выбора занятия в этом режиме нет, только время года.

**Ключевая мысль:** код — это тот же алгоритм, только на языке, который понимает компьютер.

### Демонстрация

1. Прочитать вслух ветку «зима» по блок-схеме.
2. Написать первый `if`:

```python
if season == 'winter':
    wear_winter_suit()
```

3. Показать соответствие:
   - ромб «Какое время года?» → `if season == 'winter':`;
   - прямоугольник «Надеть тёплую куртку» → `wear_winter_suit()`.
4. Выбрать «Зима» и нажать «Запустить код»: Витя надел куртку.
5. Спросить детей: «А если сейчас весна?». Добавить `elif`.
6. Дальше дети по очереди диктуют (или сами пишут) остальные ветки. Редактор подсказывает команды и значения: начните печатать `wear` или `sum`.
7. Нажать **«Проверить всё»**: платформа проверит все четыре сезона и запустит конфетти.

> **Для преподавателя:** печатайте медленно и вслух. Важнее связь схемы и кода, чем скорость.

### Готовый код (режим «Только сезоны»)

```python
if season == 'winter':
    wear_winter_suit()
elif season == 'spring':
    wear_raincoat_suit()
elif season == 'summer':
    wear_summer_suit()
elif season == 'autumn':
    wear_school_suit()
```

### Бонус: сезон + занятие (если есть время)

> **Слайд 14:** «Бонус: сезон + занятие».

Переключить платформу на **«Сезон + занятие»**. Теперь Витя выбирает ещё и занятие: лыжи, коньки, кораблики, рыбалку и т. д. Это **вложенные условия**: внутри ветки сезона появляется ещё один `if`.

```python
if season == 'winter':
    wear_winter_suit()
    if activity == 'skiing':
        take_skis()
    elif activity == 'skating':
        take_skates()
```

Полная таблица вариантов и эталонный код — в [master-class-plan.md](master-class-plan.md) (разделы 5–6) и [README.md](README.md).

> **Внимание:** в полном режиме лето и осень без занятия — это «обычный вид Вити», без одежды из упрощённого режима. Код из упрощённого режима здесь проверку не пройдёт, и это нормально: задача стала другой.
